=== _Basics_

* https://www.haskell.org/alex/[Alex] - a lexical analyser generator for
Haskell.
* https://www.haskell.org/cabal/[Cabal] - a system for building and
packaging Haskell libraries and programs.
* https://www.haskell.org/ghc/[GHC] - the state-of-the-art optimizing
native code compiler for Haskell.
* https://downloads.haskell.org/~ghc/latest/docs/html/users_guide/ghci.html[GHCi]
- a bytecode interpreter and interactive REPL environment for Haskell.
* https://www.haskell.org/ghcup[GHCup] - GHCup is the main installer for
the general purpose language Haskell.
* http://hackage.haskell.org/[Hackage] - the Haskell community’s central
package archive.
* https://www.haskell.org/haddock/[Haddock] - a tool for automatically
generating documentation from annotated Haskell source code.
* https://www.haskell.org/happy/[Happy] - The Parser Generator for
Haskell.
* http://hayoo.fh-wedel.de/[Hayoo] - will search all packages from
Hackage, including all function and type definitions.
* https://www.haskell.org/hoogle/[Hoogle] - a Haskell API search engine,
which allows you to search many standard Haskell libraries by either
function name, or by approximate type signature.
* https://github.com/Paczesiowa/hsenv/[hsenv] - a tool to create
isolated Haskell environments. This allows a project to use a GHC
version different of the currently installed.
* https://github.com/commercialhaskell/stack[Stack] - a cross-platform
tool to help on building Haskell projects. It includes support to create
isolated Haskell environments and to automatically manage the
dependencies of a project.
* https://github.com/fpco/stackage[Stackage] - "`Stable Hackage,`" tools
for creating a vetted set of packages from Hackage.

=== Packages

* https://www.stackage.org/[Stackage] - is a stable source of Haskell
packages, "`Stable Hackage`".
* http://hackage.haskell.org/[Hackage] - is the Haskell community’s
central package archive.
* https://wiki.haskell.org/Applications_and_libraries[Application &
Libraries] - Official collections and Guide.
* https://www.haskell.org/hoogle/[Hoogle] - is a Haskell API search
engine, which allows you to search many standard Haskell libraries by
either function name, or by approximate type signature.
* http://hayoo.fh-wedel.de/[Hayoo] - will search all packages from
Hackage, including all function and type definitions.
